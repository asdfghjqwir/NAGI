# NAGI. 〜一人の職人が、一つずつ〜

少ない数しか作れない革小物を、「少ないからこそ価値がある」と伝える1ページのブランドサイトです。

 https://nagi-inky.vercel.app/

※訓練校の課題として制作したサイトです。ブランド名・人物・店舗・商品は架空です。

## 概要

大量には作れない一人の職人の革小物を、50代以上の男性に向けて、静かに見せることを目的に制作しました。
色・書体・商品・お店の数をすべて絞り、「足さないことで、価値が伝わる」という考え方を、サイトの作り方にも取り入れています。

## 主な機能

- ヒーロー・職人紹介・商品3つ・買えるお店の、1ページ構成
- スクロールすると、文章がじんわり現れる(ページを開いたときは、トップの文字が1つずつ現れる)
- ナビと「↑」ボタンで、見たい場所へゆっくり移動
- スマホでも見やすいように、画面がせまいときは1列に並べ替え

## 使用技術

HTML / CSS / JavaScript、Google Fonts

1ページだけの小さなサイトなので、特別な道具は使わず、HTML・CSS・JavaScriptだけで作りました。

## 工夫した点

- 色はクリームと墨色の2色だけ。薄い文字も、墨色を薄めて作り、色を増やさなかった
- スクロールの動きは、JavaScript 22行だけで作った。スクロールしない画面(画面の写真を撮るときなど)でも、文章や写真が消えないようにした
- 同じ指定は1か所にまとめて、コードを短くした

## 今後の改善点

- 今は無料の写真を使っているので、実際の商品の写真に差し替える
- 商品をクリックすると、くわしい説明(大きさ・素材など)が見られるようにする
